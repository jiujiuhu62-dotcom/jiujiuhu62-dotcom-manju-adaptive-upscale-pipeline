# 验证口径

功能检查采用程序生成样本与本机模拟 ComfyUI HTTP；核心包含输入验证、API 格式兼容、续跑失效、异常隔离、RGBA、MCP 及图像指标等测试。独立 SSIM 交叉核验需要可选的 scikit-image。

内部效果实验：12 张作者原创角色海报，约四倍宽高降采样后增加低清高斯模糊半径 0.6。插值与 AI 接收同源输入，输出与内部基准尺寸对齐。原图、私有实验记录、截图和录屏不随源码发布。

平均 RGB PSNR：23.700 → 24.096 dB；Y SSIM：0.71702 → 0.73923。3 张 PSNR、2 张 SSIM 下降。PSNR/SSIM 均裁边 4 像素；SSIM 为 11×11 高斯窗、sigma 1.5、population 协方差、有效窗口。记录只说明该人工退化条件，不代表自动美术验收。

两张 README 示例均重新缩小、压缩并移除图像元数据；它们用于视觉说明，不能用于重新计算原实验指标。没有从视频中截图，因此不带聊天、提示词或桌面隐私。

2026-11-05 在独立验证副本中运行：32 项单元测试全部通过，包括独立 SSIM 交叉核验；离线演示首次 4 张成功、0 失败，第二次 4 张复用、0 失败。测试产物与原始终端日志留在发布目录之外。本轮没有重新执行真实 GPU 超分；README 的画质指标来自此前内部实验。
